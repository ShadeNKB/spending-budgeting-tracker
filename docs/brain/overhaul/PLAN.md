# Overhaul plan

Approved by the lead under Shade's delegation ("Anything is up to you", 18 Oct 2026). Source: `FINDINGS.md` (117 merged findings, 6 P0 / 25 P1 confirmed by 3-lens adversarial verification) and the auditors' improvement ideas.

## Principles

1. **Data safety first.** Nothing ships that can lose a row of Shade's real, synced history. Every data-shape change is additive, versioned, migration-tested, and tested against an older client.
2. **Correct numbers before pretty screens.** A finance app that shows a wrong total is broken, whatever it looks like.
3. **Refine the warm/soft design, don't replace it.**
4. **Every track ships alone**: own branch and worktree, test-first for logic, three-lens independent review, full gates plus e2e, CI green, release.
5. **Budget-aware.** About 47 KB of raw JS headroom. New weight must be lazy or offset by cuts (framer-motion is the main lever).

## Gates per track

`npm run verify` (typecheck · lint · format · unit tests · build · size · smoke) plus unit tests in 3 timezones (PowerShell `$env:TZ`; Git Bash does not honour IANA TZ on Windows), e2e on Chromium + WebKit, three-lens independent review (correctness/data safety · real-browser UX/a11y at 375 px and 1280 px in both themes · regression and gates), CI green, then merge and release.
